## 一、高考数学真题库.html

### 功能
- **按年份/卷别浏览**：左侧边栏从 2026 倒序到 1952，共 64 个年份、775 套试卷
- **知识点筛选**：15 个知识模块（集合与逻辑、复数、平面向量、三角函数、数列、不等式、函数与导数、立体几何、解析几何、概率统计、排列组合二项式、算法框图、极坐标参数方程、矩阵变换、其他）
- **题型筛选**：单选题、多选题、填空题、解答题、选考题
- **全文搜索**：顶部搜索框，实时过滤题干+答案+解析
- **答案解析折叠**：每题点击"显示答案与解析"展开
- **暗色模式**：右上角 🌓 切换
- **移动端适配**：手机上侧边栏可收起

## 二、从零推导-导数.html

### 章节结构（8 章）
1. 前言：为什么要学导数
2. 平均变化率（从速度公式开始）
3. 极限的直观（割线逼近切线）
4. 导数的严格定义
5. 从定义推基本导数公式（常数、一次、幂函数、sin/cos）
6. 求导四则法则与链式法则
7. 导数与函数单调性
8. 极值与最值（含高考压轴题通法）

### 特点
- KaTeX 字体全部 base64 内联，离线可开，公式不会显示成源码
- 每章有前置知识提示（黄色框）和后续应用（绿色框）
- 生活直觉用绿色框标注
- 完整代数推导不跳步
- 移动端适配
